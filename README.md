# AI Voice Calling Agent

An AI-powered voice calling system capable of handling both inbound and outbound phone calls using natural language conversation.

## Overview
This project demonstrates a scalable voice-based communication system designed for organizations and government use cases such as election awareness, public service communication, and customer support.

## Key Features
- Inbound and outbound voice calling
- Natural language conversation (no IVR menus)
- Multi-language support
- Context-aware responses
- Scalable and cost-efficient design

## System Architecture
Telephony → Backend → Speech-to-Text → LLM → Text-to-Speech → Telephony

## Tech Stack
- Twilio Voice API
- Speech-to-Text (ASR)
- Large Language Model (LLM)
- Text-to-Speech (TTS)
- Python (FastAPI / Flask)

## Use Case
Election awareness and citizen communication during large-scale public operations.

## Notes
This repository contains a prototype implementation created for a hackathon and focuses on demonstrating feasibility and system design.
